# Starter data

Run `python scripts/generate_demo_data.py` to create signal, background, and collision-like CSV files.

Each event contains an opposite-sign same-flavor electron or muon pair, an event weight, and per-lepton pT, eta, phi, mass, charge, and flavor. The signal has a narrow Z-like mass distribution and a simple spin-one-inspired angular distribution. The background is smooth and schematic. A common boost gives the pair longitudinal motion and transverse recoil.

These samples preserve four-vector consistency, but they are not collider data, detector simulation, parton showering, or a physical matrix-element calculation. Do not use them for precision claims.
